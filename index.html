About This Map

This is an educational visualization for a cybersecurity classroom — not a security monitoring tool. Here's exactly what's real and what isn't.

Real data

  • SANS ISC / DShield — recently reported scanning/attack source IPs from a global volunteer sensor network.
  • CINS Army — a community-maintained list of IPs with a history of malicious activity.
  • abuse.ch Feodo Tracker — currently or recently active botnet command-and-control servers, labeled by malware family (e.g. Emotet, QakBot).

Source locations are real, resolved from each reported IP address via ipwho.is. IP geolocation is approximate — it sometimes reflects a cloud/hosting provider's location rather than the attacker's true location.

Not real

  • Destination points — none of these feeds report a real attacked target. Every arc's endpoint is chosen randomly from six fixed illustrative points, one per continent, purely so arcs don't all converge on one spot.
  • Dimmed grey arcs — fully simulated placeholder data, shown only if the live SANS ISC feed can't be reached. Always marked separately in the legend and activity log.

Refresh rate

SANS ISC is polled directly every 45 seconds. CINS Army and Feodo Tracker are refreshed every 30 minutes by a scheduled job (their sites don't support direct browser requests), then checked from that local copy about once a minute.
